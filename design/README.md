# Design

Proposals for the v2 app. Both are self-contained HTML — open in a browser.

| File | What it is |
|---|---|
| `01-three-concepts.html` | Three complete alternative designs (Copertura, In Città, La Serie), 27 screens, with a comparison and a recommendation. Superseded by 02, kept for the reasoning. |
| `02-la-citta.html` | **Current design.** The merged app: city-map home screen, task scenes, the word workshop, and the generated serial. 21 screens on one design system. |

The evidence behind every design decision is in [`../research/`](../research/).
